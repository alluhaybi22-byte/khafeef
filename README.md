# خفيف — صور وملفات PDF

نسخة تطوير لتجهيز الملفات فقط؛ لا تحتوي على تصحيح بالذكاء الاصطناعي أو أتمتة. لم تُنشر هذه النسخة.

## الوظائف
- تصوير المستندات أو استيراد صور وملفات PDF متعددة في عملية واحدة.
- معاينة كل صفحة، وتدويرها، وقصها بسحب مستطيل فوق الصورة. يمكن إلغاء القص.
- ترتيب الصفحات بسحب البطاقة على الكمبيوتر، أو الضغط المطوّل ثم السحب على الجوال. بديل واضح: تحديد موضع الصفحة بالأرقام من المعاينة؛ وAlt+سهم أعلى/أسفل عند تركيز البطاقة.
- حذف صفحة أو مسح الجلسة بعد تأكيد.
- حفظ الصفحة المختارة كصورة JPEG مع الجودة المحددة.
- دمج الصور وPDF في ملف واحد بالترتيب الظاهر.
- تجهيز الناتج ثم معاينته وتنزيله، أو مشاركته إذا كان المتصفح يدعم مشاركة الملفات.

## طريقتا الإخراج
1. **حفظ صفحات PDF الأصلية:** يحافظ على النصوص في صفحات PDF غير المقصوصة، مع إمكانية تدويرها. الصور تُوضع على A4. قص صفحة PDF يحوّل تلك الصفحة فقط إلى صورة.
2. **ضغط جميع الصفحات كصور:** ثلاث درجات جودة. صفحات PDF تحتفظ بأبعادها المرئية، والصور تُوضع على A4. النصوص في الناتج تصبح غير قابلة للبحث أو التحديد. تقليل الحجم غير مضمون؛ يعرض التطبيق الحجم النهائي والمقارنة بالملفات المصدر، وليست مقارنة مع نسخة غير مضغوطة من الناتج.

القص مستطيل يدوي؛ لا يتضمن تصحيح منظور أو اكتشاف حواف آلي. هذه أداة للمستندات الثابتة؛ لا يُضمن حفظ النماذج التفاعلية أو التوقيعات الرقمية وخصائص المستند المتقدمة عند الدمج.

## التشغيل والحدود
- تُعالج الملفات محليًا في ذاكرة المتصفح ولا تُرفع لخادم. احفظ الناتج قبل إغلاق الصفحة؛ لا يوجد حفظ دائم للجلسة.
- تحتاج المكتبات الخارجية اتصالًا بالإنترنت عند التحميل: pdf-lib 1.17.1 وPDF.js 5.4.296.
- الكاميرا تحتاج HTTPS أو localhost مع السماح باستخدامها. تشغيل HTML من تطبيق الملفات على آيفون لا يكفي لاختبار الكاميرا.
- حد العملية: 150 صفحة، 80 ميجابايت للملف الواحد، و200 ميجابايت لمجموع الملفات المصدر. قد يحتاج الجهاز الضعيف عمليات أصغر.
- لا تدعم النسخة ملفات PDF المحمية بكلمة مرور. الاستيراد الفاشل لا يحذف الملفات السابقة.
- أثناء المعالجة تُعطّل أدوات التعديل لمنع تغير الصفحات أثناء التصدير.
- لا تغيّر جودة الصورة الأصلية؛ الحفظ ينشئ نسخة جديدة.

## التحقق
اختُبرت بملفات وهمية في Chromium وبمقاس شاشة جوال: الاستيراد المختلط، الضغط المطوّل لإعادة الترتيب، الترتيب بلوحة المفاتيح، القص، تدوير الصور وPDF، عدد صفحات الناتج، بقاء النصوص في الوضع الأصلي، فقد البحث النصي المتوقع في وضع الضغط، رفض PDF التالف، وإبطال الناتج السابق بعد التعديل.

لم تُختبر على Safari أو جهاز آيفون حقيقي بعد. الكاميرا ومشاركة iOS تحتاجان تجربة فعلية قبل اعتماد الإصدار.

لتشغيل الاختبارات:
```sh
npm install
npx playwright install chromium
npm test
```
يمكن تحديد متصفح اختبار موجود عبر `KHAFEEF_TEST_CHROME`، وتحديد مكان لقطة الاختبار عبر `KHAFEEF_TEST_SCREENSHOT`. مكتبات الاختبار تأتي من الحزم المثبتة بنفس إصدارات التطبيق لتجنب الاعتماد على اتصال CDN أثناء الاختبار.
