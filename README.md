# خفيف Web v2

هذه نسخة PWA مخصصة للمتصفح والآيفون.

الجديد:
- كاميرا Safari عبر getUserMedia.
- رسالة واضحة إذا لم تكن الصفحة HTTPS.
- اختيار عدة صور.
- معالجة صفحة بصفحة لتقليل تجمد المتصفح.
- شريط تقدم أثناء إنشاء PDF.
- تصغير وضغط الصور قبل إدخالها في PDF.
- ثلاث درجات جودة.
- حذف الصفحات.
- تنزيل PDF.

مهم:
لكي تعمل الكاميرا وتظهر كتطبيق عند إضافتها إلى الشاشة الرئيسية، يجب استضافة المجلد على HTTPS.
فتح index.html كملف محلي ليس طريقة مناسبة لاختبار الكاميرا.

النسخة الحالية تستخدم jsPDF من CDN، لذلك تحتاج اتصالًا بالإنترنت أثناء تحميل المكتبة.
